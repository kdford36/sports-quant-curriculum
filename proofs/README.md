# proofs/

One file per proof, named `<phase>-<slug>.md` (e.g. `1-markov-inequality.md`). Write math in LaTeX: `$...$` inline, `$$...$$` for display. VS Code's Markdown preview renders it.

Template:

```markdown
# <Theorem name>

**Statement.** ...

**Assumptions.** ...

**Proof.** ...

$\blacksquare$

**Review notes** (Claude adds these)
```
